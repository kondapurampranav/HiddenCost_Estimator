# Hidden-Cost-Estimator
A web-based construction cost estimation tool that helps homeowners calculate the additional cost of material upgrades beyond the builder's standard package.

## Overview
Builders often provide a base package with fixed material allowances. When customers choose premium materials such as better tiles, countertops, bathroom fittings, or accessories, the final cost increases significantly.

This project estimates those hidden upgrade costs and provides a detailed breakdown along with a downloadable PDF report.

## Features
- House Area Calculation
- Builder Package Cost Estimation
- Tiles & Flooring Upgrade Calculator
- Kitchen Upgrade Calculator
- Bathroom Upgrade Calculator
- Accessories Cost Calculator
- Interactive Dashboard with Charts
- Final Cost Estimation
- PDF Report Generation

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
- Chart.js
- jsPDF

## Project Objective
To provide transparency in construction budgeting by helping homeowners identify and estimate hidden material upgrade costs before construction begins.
